# ЯОФББ — сайт федерации

Адаптивный одностраничный сайт Ярославской областной федерации бодибилдинга. Визуальный стиль построен вокруг чёрного фона, золотых акцентов и авторских иллюстраций.

**Демо:** [belovdm.github.io/yaofbb-site](https://belovdm.github.io/yaofbb-site/)

## Состав

- `index.html` — разметка страниц, контент и интерактивные элементы.
- `styles.css` — адаптивные стили.
- `assets/` — оптимизированные изображения и исходные иллюстрации.

Сайт не требует сборки и сторонних пакетов. Для локального просмотра откройте `index.html` в браузере или запустите любой статический HTTP-сервер в корне проекта.

## Публикация

Сайт публикуется в GitHub Pages через GitHub Actions при каждом push в `main`. Workflow можно запустить вручную из вкладки **Actions**.

## Новости и соревнования

Новости и соревнования на сайте сверяются с публикациями [Ярославской областной федерации бодибилдинга во ВКонтакте](https://vk.ru/yaofbb_official). Даты, площадки и контакты добавляются только при наличии подтверждённого источника.

По состоянию на 3 октября 2026 года опубликованы анонсы чемпионата Ярославской области «Наследие чемпионов» (11 октября) и чемпионата Рыбинска «Воложский торнадо» (24 октября), а также анонс чемпионата города Углич в рамках фестиваля «Сила Углича» (5 сентября). Для чемпионата 11 октября место проведения в предоставленном анонсе не указано.

Протоколы, результаты, рейтинг спортсменов и отдельные ссылки на публикации требуют подтверждения. Сайт ссылается на официальную страницу федерации, не представляет демонстрационные контакты или заявки как действующие.
